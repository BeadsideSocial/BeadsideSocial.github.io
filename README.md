# Beadside Social

Website for Beadside Social, private jewelry-making parties in Palm Beach County (a Silesc Group LLC business).

Plain HTML, CSS and JavaScript — no build step. Hosted with GitHub Pages.

- `index.html` — page content
- `styles.css` — colors, fonts, layout
- `script.js` — bead illustration and the booking form. Set `BOOKING_EMAIL` at the top to the address that should receive requests.
- `gallery/` — earring photos (960×1200, JPG + WebP). To add one, drop both files here and copy one of the `<li>` blocks in the "Made at our table" section of `index.html`.
